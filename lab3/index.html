Data acquisition

Source and Method

The source is Oracle's Elixir professional match data. A Python script uses requests to download one public annual CSV, then pandas filters the 2025 LPL player rows and saves the result as data/lab3_lpl_2025.csv. The script validates that at least 1,000 records were collected and includes timeout, HTTP error handling, an informative user agent, and a delayed fallback if the download fails. Acquisition pagination is not applicable because the source is one annual file; the webpage paginates the resulting records in groups of 50.
