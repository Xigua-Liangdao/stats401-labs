Design reflection

I extended the two GDP maps from Lab 9 because finding a small economy on the world map can take more effort than comparing its value. Saying “highlight Singapore” selects it in both views and brings its GDP into the status line. “Reset” clears the selection and restores the original zoom.

Both commands use the same functions as the dropdown and reset button. The microphone listens for one command at a time, and the page shows what it heard beside the result. If a name comes through incorrectly, the mismatch is visible before the next comparison.

The CSV calls South Korea “Korea, Republic of”, so I added everyday names such as “South Korea” and “Hong Kong”. In transcript tests, an unknown name left the current selection alone. These checks cover command handling; live microphone accuracy has not been measured. Accents, background noise, and browser support still need testing. The menu remains available when speaking is inconvenient or microphone access is blocked.
