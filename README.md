## Visualization Critique and Redesign

**Data Breaches in Context** reworks Information Is Beautiful’s *World’s Biggest Data Breaches & Hacks*. The D3 bubble timeline keeps the original’s emphasis on scale, history, and individual stories, with year focus and a separate comparison of selected events.

[**Explore the individual project →**](https://xigua-liangdao.github.io/stats401-labs/individual-project/)

- [The interactive D3 redesign](https://xigua-liangdao.github.io/stats401-labs/individual-project/#explorer), using an external [JSON dataset](individual-project/data/breaches.json)
